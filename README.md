# 🎬 StreamFlix

A modern Netflix-inspired streaming platform UI built from scratch using HTML5 and CSS3.

## 🚀 Live Demo

[View StreamFlix Live]([https://pritesh-waghmare.github.io/streamflix-ui/])

## ✨ Features

- Cinematic hero section
- Featured movie showcase
- Trending movies
- Continue Watching section
- Popular movies
- Action & Adventure section
- Interactive movie cards
- Hover animations
- Responsive layout
- Dark-themed streaming interface

## 🛠️ Tech Stack

- HTML5
- CSS3

## 📚 What I Learned

- Structuring a multi-section web interface with HTML
- Building layouts with CSS
- Working with background images and overlays
- Creating interactive hover effects
- Organizing local image assets
- Deploying a static website using GitHub Pages

## 🎯 Project Goal

This project was built to strengthen my frontend fundamentals and practice turning a design concept into a complete, responsive web interface.
